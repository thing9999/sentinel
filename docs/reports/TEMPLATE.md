# <기능> · <역할> 작업 보고

> 파일 위치: `docs/reports/<feature>/<role>.md`
> 같은 기능에서 같은 역할이 다시 작업하면 새 파일을 만들지 말고 아래에 `## YYYY-MM-DD HH:mm · <작업 이름>` 섹션을 **추가**한다 (이전 섹션은 지우지 않는다).

## YYYY-MM-DD HH:mm · <작업 이름>

### 1. 요청 내용
- 누가(PM) 무엇을 요청했는지, 범위

### 2. 참고한 문서
- `docs/specs/...`, `docs/design/...`, `docs/api/...` 등

### 3. 작업 내용
- 무엇을 어떻게 만들었는지 단계별로 상세하게

### 4. 변경 파일
| 경로 | 구분(추가/수정/삭제) | 내용 |
|---|---|---|

### 5. 주요 결정과 이유
- 결정 / 검토한 대안 / 선택한 이유

### 6. 검증 결과
| 명령 | 결과 | 비고 |
|---|---|---|

- 실패하거나 건너뛴 검증은 그대로 적는다 (이유 포함)

### 7. 남은 이슈·한계
- 미완료 항목, 알려진 버그, 가정한 부분

### 8. 다른 담당 요청
- `○○ 요청`: 내용

### 9. 다음 담당이 알아야 할 점
- 사용법, 주의할 점, 인터페이스
